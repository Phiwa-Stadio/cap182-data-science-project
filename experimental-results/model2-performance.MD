# Model 2 Performance – Random Forest

## Related script

`experimental-results/model2-performance.py`

The script reads the Model 2 predictions and calculates the performance metrics and confusion matrix.

## Results

Model 2 was evaluated on the same final 20% of the data, using the same chronological train/test split as Model 1.

| Metric | Result |
|---|---:|
| Accuracy | **0.8218** |
| Precision | **0.0654** |
| Recall | **0.1783** |
| F1-score | **0.0954** |
| ROC-AUC | **0.5571** |
| Training records | 77,176 |
| Testing records | 19,294 |

## Interpretation

The Random Forest achieves a higher accuracy of **82.2%**. However, its recall is much lower at **17.8%**, so it identifies fewer of the orders that were actually late.

Its precision is also low at **6.5%** and its ROC-AUC of **0.557** indicates limited separation between the two classes in the current setup.

Because late delivery is the class of operational interest, accuracy should not be considered on its own.

## Statistical measures

The performance script also calculates:
- confusion matrix;
- specificity;
- balanced accuracy;
- Matthews correlation coefficient (MCC);
- classification report.

These provide additional information about both classes and reduce reliance on accuracy alone.

## How to run

From the repository root:

```bash
python experimental-results/model2-performance.py
```

The script expects:

```text
models/artifacts/model2/predictions.csv
```

which is generated by:

```bash
python models/random-forest.py
```
