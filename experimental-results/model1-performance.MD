# Model 1 Performance – Logistic Regression

## Related script

`experimental-results/model1-performance.py`

The script reads the Model 1 predictions and calculates the performance metrics and confusion matrix.

## Results

Model 1 was evaluated on the final 20% of the data, using a chronological train/test split.

| Metric | Result |
|---|---:|
| Accuracy | **0.5641** |
| Precision | **0.0911** |
| Recall | **0.8606** |
| F1-score | **0.1637** |
| ROC-AUC | **0.7020** |
| Training records | 77,176 |
| Testing records | 19,294 |

## Interpretation

The model identifies a large proportion of the late deliveries, as shown by its high recall of **86.1%**. However, its precision is low at **9.1%**, meaning that many orders predicted as late were actually on time.

The ROC-AUC of **0.702** indicates that the model has useful ability to distinguish between late and non-late orders, although there is still substantial room for improvement.

The difference between accuracy and recall should be considered together with the class distribution. Accuracy alone is not a sufficient measure for this problem.

## Statistical measures

The performance script also calculates:
- confusion matrix;
- specificity;
- balanced accuracy;
- Matthews correlation coefficient (MCC);
- classification report.

These measures provide a fuller view of performance, particularly where the two classes are not evenly represented.

## How to run

From the repository root:

```bash
python experimental-results/model1-performance.py
```

The script expects:

```text
models/artifacts/model1/predictions.csv
```

which is generated by:

```bash
python models/logistic-regression.py
```
